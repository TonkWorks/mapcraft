# MapCraft

MapCraft is a fork of [EffectCraft](https://github.com/storytold/effectcraft) focused on **animated
maps and battlemaps for YouTube videos**: the explainer-map look (globe zooms, highlighted countries,
routes drawing on, pinned photos) and the war-map look (unit symbols, attack arrows, front lines,
territory changing over a date timeline). It runs natively and in the browser, and maps can be
described in plain English, generated by an AI, then edited by hand.

Everything EffectCraft does still works; map features are additive, mostly in new crates, so the fork
keeps merging upstream (`git fetch upstream && git merge upstream/main`).

## Design

- **Map layers are ordinary layers.** Effects, masks, blend modes, parenting, track mattes and
  expressions all apply to them.
- **Geography is animatable.** Center (lon, lat), Zoom, Rotation and Projection are properties
  with keyframes. `map.flyTo` bakes a smooth zoom-out / pan / zoom-in move (van Wijk & Nuij 2003)
  into those keyframes, so it stays editable in the Graph Editor.
- **Everything is a command** (`layer.newMap`, `map.set`, `map.flyTo`, …), reachable from the UI,
  the CLI, the control channel and MCP. This is what the AI drives.
- **AI writes a spec, not layers** (planned). A BattleMap Spec (JSON: region, style, forces, dated
  beats with camera moves, unit moves, arrows, territory) is the editable source of truth. An LLM
  edits the spec through tool calls with a place lookup (no guessed coordinates). A deterministic
  compiler turns the spec into ordinary layers, keeping hand tweaks as overrides.
- **Offline, openly licensed data.** Natural Earth (public domain) now; Protomaps PMTiles
  (OpenStreetMap, ODbL), Copernicus DEM, NASA Blue Marble and GeoNames later, each attributed.
  Check the terms before bundling any of them.

## Try it

```sh
cargo run --release -p effectcraft-cli -- --empty run \
  comp.new '{"name":"Ukraine","width":1920,"height":1080,"frameRate":30,"duration":6}' \
  layer.newMap '{"center":[-30,25],"zoom":0.2,"highlight":["UKR"]}' \
  map.flyTo '{"layer":1,"place":"Ukraine","time":0.5,"duration":4}' \
  --save-as ukraine.ecproj
cargo run --release -p effectcraft-cli -- --project ukraine.ecproj render --out ukraine.mp4 --format h264
```

`projection` is `equirectangular`, `mercator` or `globe`. `place` and `highlight` take country names or
ISO 3166-1 alpha-3 codes.

## Roadmap

| Phase | Goal | Contents |
|---|---|---|
| 0. Spike ✅ | Prove the fork | `crates/geo`, Map layer source, world basemap, globe, `layer.newMap` / `map.set` / `map.flyTo`, native + web builds |
| 1. Map core | Explainer-map comp | Level of detail (1:50m / 1:10m, then vector tiles), graticule, country lift / glow / shadow, routes that draw on, pins and labels with collision avoidance, place search, style presets, Map panel in the UI |
| 2. Battle kit | War-map comp by hand | NATO APP-6 unit symbols, tapered curved attack arrows, front lines with teeth, territory over a date timeline (polygon morphs), date → comp-time mapping, CSV / KML / GPX import |
| 3. Spec + Map Studio | Easy editing | BattleMap Spec + compiler, a simple beat-list workspace (click to place units, drag arrows, paint territory), "Open in Timeline", YouTube export presets (16:9, Shorts 9:16, alpha) |
| 4. AI | English → map | LLM tool calls over the spec (bring your own key; Claude by default), place lookup, follow-up edits ("slow the second beat"), a prompt eval set |
| 5. Globe & terrain | Polish | Satellite imagery, DEM terrain and hillshade, atmosphere, globe ↔ flat morph, 3D models along paths |

## Before a public release

- **Brand marks:** `AGENTS.md` §1.8 and `docs/brand/LICENSE-brand.txt` require forks to remove the
  ArtCraft name and logos (app icon, About window, community links). Rebrand before distributing
  builds.
- **Borders are political:** Natural Earth draws de facto boundaries (for example Crimea). Offer its
  point-of-view variants and let creators pick.
